# Facebook local and community groups

**Status: drafts. Nothing posted, no admin messaged.** Each message and post is the owner's action
from the owner's own profile.

## Rule check

Facebook has no site-wide rule against sharing your own project in a group; each group's admins
set the rules, shown under the group's "About" tab. Most local buy-nothing, neighborhood and
couponing groups either ban promotion or limit it to one weekly thread, and admins remove first
and explain later. `compliance.md` rule 45: read each group's rules before posting, and never
post into a group that bans promotion.

So the order is always: read the rules, message an admin, post only on a yes.

## Which groups

Only groups the owner already belongs to and takes part in. Likely fits:

- neighborhood and town groups in the owner's own area (Chicago, where 60618 has been tested);
- local "frugal living", "budget meals" or "grocery deals" groups for that area;
- a group's weekly "local business / what are you working on" thread, where one exists.

Not: buy-nothing groups (gifting only), any group whose rules say no promotion, or groups in
cities where the list has not been run within 24 hours. Three or four groups in total, not
thirty; the same post pasted across many groups is what gets a profile restricted.

## Message to the admin

```
Hi [name]. I'm a member here and I live in [neighborhood]. I built a free website that compares grocery prices at the stores near a ZIP code, and it has a Thanksgiving list on it right now. There's no sign-up and no ads. Would it be OK if I shared it once in the group, saying clearly that I made it? If you'd rather I didn't, or there's a certain day for this kind of thing, no problem at all.
```

## The post (only after an admin says yes)

```
Neighbors: I made something that might help with the Thanksgiving shop. Saying up front that it's mine.

It's a free website called Cartworth. You put in your ZIP and it shows what an item costs at the grocery stores around here, all in the same unit (per pound, per gallon), so a small box and a big bag can be compared. It also shows each store's weekly ad with the fine print: "limit 1", "with card", "with $25 purchase".

For Thanksgiving there's a ready-made list, turkey to pie crust. Add the sizes you'll actually buy ("whole turkey 14 lb") and it shows what the whole list costs at each store, and whether a second stop is worth the drive.

No sign-up, no ads, and I'm not affiliated with any store. It can't promise you'll save anything; it shows what each store is publishing today, and stores do change prices, so check the shelf tag.

https://cartworth.app/guides/thanksgiving-dinner-prices

If it gets something wrong for a store near us, tell me and I'll fix it.
```
